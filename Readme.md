<h2 align="center">👨‍💻 Sobre mim</h2>

<img align="right" width="200" src="https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif" />

Olá! Eu sou o **Maurício Oliveira**, QA Engineer na **NTT DATA**. Trabalho com meios de pagamento — já passei por Pix, câmbio (FX) e adquirência — e hoje estou somando DevOps e Cloud à minha bagagem de qualidade.

Gosto de automatizar o que é repetitivo, testar API até quebrar (e depois ajudar a consertar) e transformar o que aprendo em projetos aqui no GitHub.

- 🏢 QA Engineer na NTT DATA (cliente Getnet/Santander)
- 🤖 ~50 cenários automatizados com Cypress rodando em Jenkins e Bitbucket
- 🔌 100+ APIs e microsserviços testados
- ☁️ Em transição para DevOps & Cloud
- 🚀 Projeto atual: [promtest](https://github.com/mauriciofeoli/promtest)
